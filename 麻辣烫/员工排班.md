# 麻辣烫店各岗位各时段工作明细表

## 一、前提说明

1. 核心岗位：前台点单收银岗、后厨烫煮备菜岗、全能保洁补位岗（3大岗位覆盖门店全部工作，无遗漏）；
2. 营业时间：8:00-凌晨1:00，时段划分：早班（8:00-17:00）、晚班（16:00-凌晨1:00），各岗位含1小时午休（早班午休12:00-13:00，晚班午休20:00-21:00）；两班重叠1小时（16:00-17:00），用于工作交接，确保衔接无空缺；
3. 重点标注：客流高峰时段（11:30-13:30、17:30-19:30、21:30-23:00），各岗位工作重点倾斜，确保效率（新增夜间小高峰，适配晚班时长）；
4. 表格说明：“具体工作内容”需严格执行，做到“时段清、责任明”，避免推诿，下班前需完成本时段收尾工作；晚班需重点做好夜间安全检查。

## 三、补充提醒

- 1. 所有岗位午休时段，需提前与同岗位人员或全能岗衔接，确保岗位无空缺，不影响正常运营；早班午休12:00-13:00、晚班午休20:00-21:00，避开客流高峰。
- 2. 两班重叠1小时（16:00-17:00）为交接时段，所有岗位需认真完成交接，填写交接记录表，明确剩余物资、工作重点及异常情况，避免衔接失误。
- 3. 卫生要求：所有与食材接触的工具（刀具、菜板、烫煮锅）需定时消毒，前厅、后厨每日收尾需彻底清洁，杜绝卫生隐患；晚班需重点清理夜间残留垃圾，避免滋生细菌。
- 4. 补位原则：全能岗优先填补前台、后厨空缺，若全能岗忙碌，前台、后厨人员可交叉补位（如前台不忙时协助收拾餐桌，后厨不忙时协助清理垃圾）；夜间高峰可灵活调整补位重点。
- 5. 晚班收尾重点：所有岗位需在凌晨1:00前完成收尾工作，重点检查燃气、水电、门窗关闭情况，做好夜间安全防护，杜绝安全隐患；食材、物资需妥善存放，避免浪费和损坏。
